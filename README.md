# Frontend Web Development Labs & Portal

A collection of responsive frontend web development exercises and interactive interface modules built with semantic HTML5, modern CSS3, and vanilla JavaScript.

## Overview

This repository houses a central landing portal (`index.html` and `ammar.css`) alongside a progressive series of hands-on web development labs (`lab-01` through `lab-15`). The modules cover core layout architecture, custom stylesheet design, responsive components, and client-side DOM interactivity.

## Repository Structure

```text
├── index.html          # Main landing page & lab navigation portal
├── ammar.css           # Primary stylesheet for the landing interface
├── lab-01/             # Lab 01 — Core document structure & semantics
